# Odoo 17 Custom Addons

Custom modules developed for Odoo 17.

## Modules

### 1. App One — Real Estate Management
- Property management
- Owners and property tags
- Custom views and menus
- Property reports
- Sale order and contact customizations

### 2. To-Do App
- Task management
- Custom task views and menus
- Access control configuration

## Requirements

- Odoo 17.0
- Python dependencies required by Odoo

## Installation

1. Clone this repository.
2. Add the repository path to your Odoo `addons_path` configuration.
3. Restart the Odoo server.
4. Enable Developer Mode.
5. Update the Apps List.
6. Install the required modules from the Apps menu.

## Repository Structure

- `app_one/` — Real estate management module.
- `to_do_app/` — To-do task management module.
